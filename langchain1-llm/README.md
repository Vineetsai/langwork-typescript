# LangChain 1-LLM Tutorial

**Basic LangChain with LLM Integration**

This tutorial introduces the fundamentals of LangChain by building a simple mathematical agent that uses custom tools with an LLM.

## Overview

This example demonstrates:
- Setting up LangChain with Ollama and DeepSeek model
- Creating custom tools for mathematical operations
- Binding tools to an LLM
- Measuring performance and token usage
- Basic agent invocation patterns

## Prerequisites

- Node.js (v16 or higher)
- Ollama installed and running on `http://localhost:11434`
- DeepSeek model: `ollama pull deepseek-r1:1.5b`

## Installation

```bash
npm install
```

## Project Structure

```
langchain1-llm/
├── main.ts          # Main application file
├── tools.ts         # Custom mathematical tools
```

## Key Components

### 1. LLM Setup (`main.ts`)

Uses ChatOllama with DeepSeek model:
```typescript
const llm = new ChatOllama({
    model: "deepseek-r1:1.5b",
    temperature: 0.7,
    baseUrl: "http://localhost:11434",
});
```

### 2. Custom Tools (`tools.ts`)

Four mathematical tools implemented:
- **addition**: Adds two numbers
- **subtraction**: Subtracts two numbers  
- **multiplication**: Multiplies two numbers
- **division**: Divides two numbers

Each tool includes:
- Zod schema for input validation
- Descriptive names and documentation
- Type-safe implementations

### 3. Agent Execution

The main application:
- Binds tools to the LLM
- Measures execution time
- Tracks token usage
- Processes natural language queries

## Key Concepts Explained

### Tools
Tools are functions that LLMs can use to perform specific actions. In this example:
- Each tool has a name, description, and schema
- Zod provides runtime type validation
- Tools are exported and bound to the LLM

### Token Usage
LangChain automatically tracks:
- **Input tokens**: Tokens sent to the LLM
- **Output tokens**: Tokens generated by the LLM  
- **Total tokens**: Combined usage for cost monitoring

### Performance Monitoring
The example demonstrates basic performance tracking by measuring the time between invocation and response.

## Troubleshooting

**Common Issues:**

1. **Ollama not running**: Start with `ollama serve`
2. **Model not found**: Pull with `ollama pull deepseek-r1:1.5b`
3. **Port conflicts**: Ensure Ollama runs on default port 11434
